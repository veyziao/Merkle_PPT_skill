## 0.1.0 — 2026-11-23

首个版本基线，整理此前多轮迭代形成的能力与规范；版本号不表示全部素材和所有运行环境均已验证。

First versioned baseline consolidating the existing work. It does not imply that every asset and execution environment has been validated.

- 以 2026 Merkle Arial 模板及其母版、版式为基础，统一常规内容页标题、字体与页脚规则。
- 整理 ICON、Slide、Case、Diagram、QBR 五个参考库及对象级样式索引，支持按内容场景选择和查阅。
- 记录可编辑 PowerPoint、原生图标、图片效果、渐变分割带、时间线与结束页的使用和检查要求。
- 提供中英文说明、跨产品安装指引和视觉预览。

- Use the 2026 Merkle Arial template and its master/layouts, with shared rules for regular content titles, typography and footers.
- Include ICON, Slide, Case, Diagram and QBR libraries and object-level style references for content-led selection.
- Document editable PowerPoint objects, source icons, picture effects, gradient dividers, timelines, closing slides and review checks.
- Provide bilingual documentation, cross-product setup guidance and visual previews.
