# User-provided slide library

For detailed object styling, including fills, transparency, gradients, shadows and 3D, consult the [source object style records](source-object-styles.md) and the original source slide.

Use the [slide library](../assets/Slide%20Library%20for%20ai.pptx) and its [139-page index](slide-library-index.json) as a broad reference pool for substantive Merkle content pages, alongside the task-specific libraries when relevant. Choose candidates by the message, information relationship, content density, and intended use, rather than restricting selection to the four earlier DEMO examples. Compare relevant candidates and adapt their structures to the current material and the user's explicit instructions. The index gives each slide a stable ID such as `SL-031`, matching its original slide number, together with a Chinese description of its composition, potential uses, application guidance, source layout, and object counts.

## How to use the library

1. Search the index by the page's job, content relationship, subject, or Chinese scenario. Open or render the relevant page in the original PPT and inspect its composition, positions, and objects before adapting it.
2. Treat each page as a visual and structural reference. Select a suitable layout in the official 2026 Arial master, and use its title region, margins and body starting position as the grid. When the reference requires free placement, build it on `自定义版式`, using editable PowerPoint elements and the user's confirmed footer and type rules.
3. A `source_notes` entry records green or gray annotations and selected replacement instructions from the source. Use the note as guidance for the referenced example. Apply the current user's directions first, including the default Agenda artwork, body font sizes, optional dentsu mark and text-free Closing page body.
4. Replace demonstration text, dummy data, historical names, figures, client logos, photographs, screenshots and template instructions with material authorized for the actual project. Treat the source's business examples as examples, not new-project facts.
5. The `source_object_counts` field is a structural inventory, not an editability guarantee. Inspect the specific objects, grouping, image links, tables, and charts. Keep text, ordinary shapes and basic tables native and groupable. Keep continuous text in one auto-wrapping text box.
