The supplied logo SVG values differ from the 2025 guideline palette. Retain the supplied asset colors and proportions. If the project requires exact alignment with a newer guide, request the matching logo files or use a newer supplied official asset.

## Additional source library

The original research workspace may contain additional source files and official assets. Its path is environment-specific and is not required by the installed skill; the bundled assets and references support ordinary Merkle deck work. The optional interactive HTML catalogs are in the GitHub repository's top-level `libraries/` directory, outside the installed `merkle-ppt` folder, and must be downloaded separately for local browsing.

| Source in `Brand Assets` | Good for | Caution |
|---|---|---|
| `PPT-Horizontal/Merkle_PPT_SampleLayoutLibrary.potx` | Broad layout exploration: needs/response 54–56; roadmap 90–94; flows 139–146 | 146 pages, many teaching/sample elements. Adapt only the method. |
| `Case Study Layouts/Merkle_PPT_CaseStudyLayoutGuide.potx` | Case density and story options, especially pages 1–2, 8–10, 15–16, 23–24, 30–44 | Contains sample business content and a hidden page. |
| `PPT-Horizontal/Merkle_Icons_2026_0217.potx` | Brand icon set and tiny filled variants | Follow page 2–3 use instructions. |
| `PPT-Horizontal/Divider_Images_2026_0512.potx` | Industry/subject divider image selection | Check use rights and subject fit. |
| `Architecture Diagram Design Elements/Architecture-Diagram_Design-Elements.potx` | Ownership zones, connectors, nests, legends | Example systems and client names are not project facts. |
| `PPT-Horizontal/Merkle_PPT_Template_ARIAL_SHORT.potx` | Short layout reference | Its linked theme still declares Proxima Nova despite its name. |
| `PPT-Horizontal/2025_YearinReviewHolidayTheme_ARIAL.potx` | Holiday/year-end context | Do not use as the universal Merkle look. |

The source library also contains `Merkle-Brand-Guidelines-2025v1.0.pdf`, `design.md`, `design-patterns.md`, `design-review.md`, and the gallery index. The guide's palette page is marked DRAFT; check whether a later edition applies when strict brand certification matters.
